# Amira Mohamed Farhan — Portfolio

Personal portfolio of Amira Mohamed Farhan, AI & Machine Learning Developer and AI Instructor.

**Live site:** https://amirafarhan.github.io

Static site (HTML, CSS, vanilla JavaScript) served by GitHub Pages — no build step.

| File | Purpose |
|---|---|
| `index.html` | Page structure and content (hero, about, experience, education, contact) |
| `main.js` | Skills and project data, project filters, details dialog, scroll effects |
| `styles.css` | Dark theme, layout and responsive styles |
| `assets/` | CV (PDF), favicon, project screenshots, social preview image |

To edit projects or skills, change the `PROJECTS` and `SKILLS` arrays at the top of `main.js`.

Run locally: `python -m http.server` in this folder, then open http://localhost:8000.
